# Fictional Student Dataset

## Description
This project creates a fictional dataset of 20 students using Python.

## Dataset fields
1. Student ID
2. Department
3. Level
4. Attendance Percentage
5. Average Examination Score

## Files
- `create_dataset.py` — Python program that creates the dataset.
- `student_dataset.csv` — Generated dataset in CSV format.

## How to run
Make sure Python 3 is installed, then run:

```bash
python create_dataset.py
```

The program creates `student_dataset.csv` in the current folder.

## Note
All student records and scores in this project are fictional and are used for educational purposes only.
